# Requirement document
## Functional requirement
### 1.บันทึกการเข้า–ออกของรถ
### 2.บันทึกเวลาเข้าและเวลาออกของรถแต่ละคันได้
### 3.ตรวจสอบและแสดงจำนวนช่องจอดรถที่ว่างได้
### 4.จัดเก็บข้อมูลรถ เช่น เลขทะเบียน และประเภทรถได้
### 5.ออกบัตรจอดรถให้กับรถที่เข้ามาใช้บริการได้
### 6.รับบัตรจอดรถเมื่อรถออกจากโรงจอดได้
### 7.คำนวณค่าบริการจอดรถตามระยะเวลาที่จอดได้
### 8.รองรับการชำระเงินค่าจอดรถได้
### 9.จัดการข้อมูลสมาชิกโรงจอดรถได้
### 10.ออกรายงานสรุปรายได้และจำนวนรถที่เข้า–ออกได้

## Non-Functional requirement
### 1.ระบบต้องประมวลผลการเข้า–ออกของรถได้อย่างรวดเร็ว
### 2.ระบบต้องคำนวณค่าบริการจอดรถได้อย่างถูกต้อง
### 3.ระบบต้องมีความปลอดภัยในการจัดเก็บข้อมูลผู้ใช้งาน
### 4.ระบบต้องสามารถใช้งานได้ตลอดเวลา (24 ชั่วโมง)
### 5.ระบบต้องสามารถแก้ไขและบำรุงรักษาได้ง่าย
